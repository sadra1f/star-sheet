# Star Sheet

Generate a printable sheet filled with beautiful stars in seconds. Choose your preferred paper size and create a ready-to-print sheet for stickers, crafts, decorations, planners, scrapbooks, or anything you can imagine.

## Features

- A3, A4, and A5 paper sizes
- Print-ready layout
- Simple and lightweight

## Getting Started

### Prerequisites

- Node.js
- Yarn (classic)

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/sadra1f/star-sheet.git
cd star-sheet
yarn install
```

### Development

Start the Vite development server:

```bash
yarn dev
```

Then open the URL shown in your terminal.

### Build

Create a production build:

```bash
yarn build
```
